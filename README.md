# awesome-ai-examples
This repository is for hands on AI learning with code examples

## Project Structure

```text

│   │   └── README.md

│   │   └── README.md
│   ├── ml-basics/
│   │   └── README.md

├── java/
```

## Modules

### Python Modules
- `python/nlp-examples`: Natural language processing examples
- `python/cv-examples`: Computer vision examples
- `python/ml-basics`: Machine learning fundamentals

### Java Modules
- `java/ml-algorithms`: Java-based ML algorithm implementations
- `java/deep-learning`: Java deep learning examples

## Setup

### Python
```bash
cd python
pip install -r requirements.txt
```

### Java
```bash
cd java
mvn clean install
```
